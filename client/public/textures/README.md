# Generated textures (preview)

WebP textures produced by `tools/asset-pipeline/texture_tool.py` and loaded by
the opt-in "Textures: generated" button of the Esc menu (spec 12).

Status: candidates, owner approval pending. The procedural textures of spec 10
stay the default. A file that is missing here is skipped by the loader.

Ids: `grass`, `dirt`, `rock`, `ua-paint`, `ru-paint`, `ua-concrete`,
`ru-concrete`, `dark-metal` (512 px, converted from `<id>-512.png` to WebP quality 90).
