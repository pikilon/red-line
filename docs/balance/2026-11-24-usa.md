# USA balance, 2026-11-24

Spec 54 section 7 goal: no side above 70 % per matchup. Method: `usa-balanced`/`usa-rush`
vs `<opp>-balanced`/`<opp>-rush` (personalities matrix, Medium), all 11 maps of
`scripts/balance-tournament.sh`, 10 seeds, `armies` set to the pair, both seats
(USA as start 0 and as start 1). A full run per opponent took about 5 minutes,
so no map or seed was cut. Win share is USA wins over decided games (draws,
i.e. 27000-tick timeouts, excluded).

The demo maps are mostly draws (units never meet) or seat-locked (demo-cover
and demo-coast favour one start whatever the army), so the signal is in
first-line, river-port and hostomel. Cells are `USA wins-opponent wins` as
start 0 | as start 1 | draws.
