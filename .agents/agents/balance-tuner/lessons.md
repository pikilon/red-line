# balance-tuner lessons

Read before starting; append new entries last (format in `.agents/workflows/faction-assembly.md`).

- 2026-11-24 usa: a tournament takes ~5 min per opponent (both seats) on 32 cores; run both seats and compare USA wins over decided games, draws excluded. Demo maps are mostly draws or seat-locked, read first-line/river-port/hostomel. A +10 % cost on one unit moved nothing: pull a bigger lever or accept a result already under 70 %.
- 2026-11-25 ai personalities (#492): after editing `data/ai/*.yaml` run `node --run build:data` and rebuild `headless`; the ruleset is embedded, so a tournament without it silently replays the old data (one run wasted). Mirror tournaments (`armies` [f,f], 3 maps x 12 seeds, 9 jobs) take ~4 min. Biggest levers for balanced vs rush: 6 trucks (not 4), expensive tech buildings after the vehicle factory, earlier mechanized/armor triggers (Russia 6 % to 31 %). Shrinking task forces made it worse (a force launches only when whole, but small ones lose fights). Ukraine stays at ~7 %: a data-only fix is not enough, look at AI code (launch logic, force size vs rush). The dock queue was not the cause (rush uses 6 trucks on one supply center fine).
