# balance-tuner lessons

Read before starting; append new entries last (format in `.agents/workflows/faction-assembly.md`).

- 2026-11-24 usa: a tournament takes ~5 min per opponent (both seats) on 32 cores; run both seats and compare USA wins over decided games, draws excluded. Demo maps are mostly draws or seat-locked, read first-line/river-port/hostomel. A +10 % cost on one unit moved nothing: pull a bigger lever or accept a result already under 70 %.
- 2026-11-25 ai personalities (#492): after editing `data/ai/*.yaml` run `node --run build:data` and rebuild `headless`; the ruleset is embedded, so a tournament without it silently replays the old data (one run wasted). Mirror tournaments (`armies` [f,f], 3 maps x 12 seeds, 9 jobs) take ~4 min. Biggest levers for balanced vs rush: 6 trucks (not 4), expensive tech buildings after the vehicle factory, earlier mechanized/armor triggers (Russia 6 % to 31 %). Shrinking task forces made it worse (a force launches only when whole, but small ones lose fights). Ukraine stays at ~7 %: a data-only fix is not enough, look at AI code (launch logic, force size vs rush). The dock queue was not the cause (rush uses 6 trucks on one supply center fine).
- 2026-11-25 ai launch logic (#492 follow-up): a tournament of balanced vs rush for ukraine, russia, usa (3 maps x 12 seeds x both seats) takes only ~1.5 min on 32 cores, so budget on iterations, not minutes. The Ukraine gap was composition and build order, not army handling: opening with a vehicle factory and mechanized/armor forces (infantry weight down, mechanized from tick 600) took it 10 % to 37 %; more barracks and bigger rifle forces made it 0 %, reordering expensive tech or shifting weights alone did nothing. Zero Hour has no army-size launch threshold (it is script data), so the code change copies only its "refill before a new wave, hold while enemies are sighted": `alertRadiusCenti` (hold launch, recall attackers) and production continuing during a defense. Last tournament numbers were measured before the final cleanup of the production change; unit tests passed.
- 2026-11-25 china (#533 horde): a 3-opponent + mirror tournament (3 maps x 12 seeds, 12 jobs, 21 files) takes ~4-5 min, not 1.5; run it in the background and wait with an `until [ -s out ]` loop (a plain sleep is blocked). Do not reuse an old output dir name: the shared scratchpad holds other runs. Cost levers worked: infantry horde bonus made China 69-82 %; raising rifle/HJ/ZBL/Type 99A costs 10-25 % in one step brought it to 43-67 %. Nerfing the whole roster also lifted balanced vs rush (82 to 69 %) because the rush is weak, so no AI opening change was needed.
